# VaultRegions 🛡️
Paper 1.21.x için optimize edilmiş, LuckPerms entegreli profesyonel maden bölgesi koruma eklentisi.

## Kurulum
1. GitHub Actions kısmından veya yerelde `./gradlew build` komutunu kullanarak derleyin.
2. `build/libs/VaultRegions-1.0.0.jar` dosyasını sunucunuzun `plugins` klasörüne atın.
3. Sunucuyu yeniden başlatın.

*(Not: Sunucunuzda LuckPerms yüklü olmalıdır!)*
